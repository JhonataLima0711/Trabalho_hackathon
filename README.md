# Revalora v2 — MVP

Versão refeita com uma identidade visual e estrutura diferentes da versão anterior.

## Principais mudanças
- Tema escuro funcional nas configurações, salvo no navegador.
- Navegação superior, sem sidebar.
- Dashboard com cartão de saldo, faixa de indicadores, operações recentes e ações rápidas.
- Cadastro reduzido a empresa + e-mail + senha.
- Configurações funcionais: tema escuro, notificações e modo compacto.
- Layout responsivo para PC e celular.
- Resíduos, coletas, parceiros e carteira continuam navegáveis.
- Dados são demonstrativos para apresentação.

## Abrir
Extraia o ZIP e abra `index.html`.
