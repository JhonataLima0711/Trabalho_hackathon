# Revalora — MVP 2.0

Protótipo web B2B para demonstração do conceito de cashback de resíduos.

## Tecnologias
- HTML5
- CSS3
- JavaScript puro (Vanilla JS)
- localStorage para simulação do estado da aplicação
- GitHub Pages para hospedagem do protótipo

## O que está interativo
- Cadastro e login simulados
- Dashboard com indicadores atualizados em tempo real
- Cadastro de resíduos com cálculo de valor estimado
- Busca e filtro de resíduos
- Solicitação de coleta
- Agenda de coletas
- Confirmação de destinação, que gera créditos e atualiza a carteira
- Cancelamento de coleta
- Busca e filtro de parceiros
- Solicitação de coleta diretamente pelo parceiro
- Carteira com extrato
- Resgate de créditos
- Configurações de tema, notificações e modo compacto
- Reset dos dados de demonstração

## Fluxo recomendado para apresentação
1. Criar uma conta.
2. Cadastrar um resíduo.
3. Solicitar coleta.
4. Abrir Coletas.
5. Confirmar destinação.
6. Abrir Carteira e mostrar o crédito gerado.
7. Resgatar parte do saldo.
8. Voltar ao Dashboard e mostrar os indicadores atualizados.

## Observação
Esta versão é um MVP de demonstração. O `localStorage` substitui temporariamente um backend/banco de dados para permitir que o professor teste o fluxo sem servidor.
